# GIF Panel for After Effects

CEP-панель для Adobe After Effects, которая позволяет перетаскивать GIF прямо в активную композицию.

## Возможности
- Drag & drop GIF на панель
- Кнопка «Заменить GIF» с диалогом выбора файла
- Автоматический импорт футажа, центрирование и масштабирование
- Зацикливание GIF на всю длину композиции
- Запоминает последний GIF между запусками

## Установка

### Windows
1. Скачайте архив во вкладке **Releases**.
2. Распакуйте в любую папку.
3. Запустите файл `install.bat`.
4. Перезапустите After Effects и откройте: `Window -> Extensions -> GIF Panel`.

### macOS
1. Скачайте архив и распакуйте его.
2. Откройте Терминал (Cmd+Пробел -> "Терминал") и выполните команду (замените путь на свой):
   ```bash
   bash ~/Downloads/GifPanel-master/install_mac.command
