# GIF Panel for After Effects

CEP-панель для Adobe After Effects, которая позволяет перетаскивать GIF-файлы прямо в активную композицию и автоматически зацикливать их.

## ✨ Возможности
- **Drag & Drop:** перетаскивайте GIF-файлы прямо в окно панели.
- **Быстрая замена:** кнопка «Заменить GIF» с системным диалогом выбора файла.
- **Умное масштабирование:** автоматическое центрирование и подгонка размера GIF под вашу композицию.
- **Авто-цикл:** зацикливание анимации на всю длину композиции (через `loopOut('cycle')`).
- **Запоминание:** панель хранит путь к последнему использованному GIF между запусками.

## 🚀 Установка

Скачайте последний релиз (ZIP-архив) во вкладке **[Releases](../../releases)** и распакуйте его.

### Windows
1. Запустите файл `install.bat` (двойным кликом).
2. Перезапустите After Effects.
3. Откройте панель: `Window -> Extensions -> GIF Panel`.

### macOS
1. Откройте Терминал (`Cmd + Пробел` -> "Терминал").
2. Выполните команду, подставив свой путь к папке (папку можно просто перетащить в окно Терминала):
   ```bash
   bash /путь/к/папке/install_mac.command
