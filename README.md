# GIF Panel for After Effects

CEP-панель для Adobe After Effects, которая позволяет перетаскивать GIF прямо в активную композицию.

## Возможности
- Drag & drop GIF на панель
- Кнопка «Заменить GIF» с диалогом выбора файла
- Автоматический импорт футажа, центрирование и масштабирование под композицию
- Зацикливание GIF на всю длину композиции (через `loopOut('cycle')`)
- Запоминает последний GIF между запусками

## Установка (Windows)
1. Скачайте последний релиз (ZIP-архив) во вкладке **Releases**.
2. Распакуйте архив в любую папку.
3. Запустите файл `install.bat`.
4. Перезапустите After Effects.
5. Откройте панель: `Window -> Extensions -> GIF Panel`.

## Требования
- Adobe After Effects CC 2015 и новее (CEP 7+)
- Windows 10 / 11

## Как пользоваться
1. Откройте и сделайте активной нужную композицию в AE.
2. Перетащите GIF-файл в окно панели (или выберите через кнопку).
3. Панель автоматически добавит его в композицию по центру.
